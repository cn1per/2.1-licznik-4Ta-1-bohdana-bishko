# Mój pierwszy agent — karta obserwacji

- **Narzędzie i model:** Cursor — Grok 4.6
- **Moje zadanie (2–3 zdania):** Stworzenie prostej aplikacji desktopowej w Pythonie, która zlicza kliknięcia użytkownika. Aplikacja ma wyświetlać aktualną liczbę kliknięć oraz przyciski „Kliknij” i „Resetuj”.
- **Pierwsza wiadomość (wklejona co do znaku):**

Stwórz prostą aplikację desktopową w Pythonie z wykorzystaniem biblioteki Tkinter, która będzie licznikiem kliknięć. W oknie ma być widoczna aktualna liczba kliknięć oraz dwa przyciski: „Kliknij” i „Resetuj”. Aplikacja działa poprawnie, jeśli każde naciśnięcie przycisku „Kliknij” zwiększa licznik o 1, a przycisk „Resetuj” ustawia jego wartość na 0. Wszystkie pliki aplikacji utwórz wyłącznie w aktualnym folderze projektu.

- **Co agent zrobił najpierw:** Agent przeanalizował polecenie i przygotował kod aplikacji w Pythonie. Utworzył plik z kodem programu, który zawiera okno, licznik oraz dwa przyciski.
- **O co pytał — i co zostało zatwierdzone bez czytania:** Agent mógł zapytać o zgodę na zapisanie plików lub uruchomienie poleceń w terminalu. Zatwierdzałam tylko te czynności, które uznałam za potrzebne do wykonania zadania.
- **Pierwszy błąd i co agent z nim zrobił:** Podczas tworzenia aplikacji nie zauważyłam poważnego błędu. Agent przygotował kod, który należało uruchomić i sprawdzić.
- **Stan po 25 minutach:** Działa.
- **Skąd wiem, że aplikacja działa (co zostało sprawdzone):** Uruchomiłam aplikację i sprawdziłam, czy licznik zaczyna od 0, zwiększa się po kliknięciu przycisku „Kliknij” oraz wraca do 0 po naciśnięciu „Resetuj”.
- **Rzeczy, które agent zrobił, a których nie rozumiem:** Nie rozumiem jeszcze dokładnie wszystkich elementów kodu Pythona i sposobu działania biblioteki Tkinter, ale wiem, do czego służą przyciski i licznik.
- **Jak mi się wydawało, że poszło (jedno zdanie):** Uważam, że zadanie poszło dobrze, ponieważ dzięki agentowi AI udało mi się przygotować aplikację bez samodzielnego pisania całego kodu.
